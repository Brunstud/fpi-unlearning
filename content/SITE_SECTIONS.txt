Recommended one-page section order

1. Hero
   - Paper title
   - Authors / affiliation only when anonymity policy permits
   - Paper / Code / Dataset / Models buttons
   - Short headline: "Forgotten ≠ Erased."

2. Introduction
   - Why private-information unlearning matters
   - Core question: erased or merely suppressed?

3. Private Information Unlearning
   - Explain the task and why structured private attributes differ from broad knowledge unlearning

4. FPI Dataset
   - Synthetic profiles
   - Four private-information attributes
   - Dataset statistics
   - Link to Hugging Face dataset

5. White-box Auditing
   - Auditor setting
   - Why standard decoding can underestimate retained information

6. Recovery Methods
   - Restricted Inverse Greedy (RIG)
   - Restricted Greedy (RG)
   - Keep equations concise; favor visual explanation

7. Main Results
   - Use selected paper figures
   - Emphasize gap between apparent forgetting and audited recoverability
   - Include retrain-from-scratch reference where appropriate

8. Additional Findings
   - Optional: learning-rate tradeoff, quantization, beam-search, model replication
   - Keep this secondary to the main result

9. Resources
   - Paper
   - Code
   - Dataset
   - Models
   - BibTeX

10. Footer
   - Minimal academic-project footer
